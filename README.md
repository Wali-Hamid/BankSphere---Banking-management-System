# 🏦 BankSphere – Banking Management System

BankSphere is a simple Banking Management System developed using **C++** for the backend and **HTML, CSS, and JavaScript** for the frontend. It provides basic banking operations through a web-based interface.

## ✨ Features

- 🧑‍💼 Create and view bank accounts
- 💰 Deposit money
- 💸 Withdraw money
- 🔄 Transfer money between accounts
- 📜 View transaction history
- 🌐 Web-based user interface
- ⚡ Local HTTP server using C++ Winsock

## 🛠️ Technologies Used

- **Backend:** C++
- **Frontend:** HTML, CSS, JavaScript
- **Networking:** Windows Winsock
- **Data Exchange:** HTTP and JSON
- **Compiler:** GCC / MinGW
